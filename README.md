# CSS Selectors
# Description
A clean frontend project demonstrating the practical use of fundamental CSS concepts , use of various CSS selectors and targeting specific elements without relying on unnecessary classes or IDs.
# Key features implemented
 1. Size Overriding
 2. Targeted Word Styling
 3. Use of Class Selectors , ID Selectors , Element Selectors and Pseudo Class Selectors
# Technologies Used
HTML 5
# How to Run
1. Download the project files.
2. Open index.html in any web browser.
